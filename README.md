# SpendWise

## Project Description

SpendWise is a responsive personal finance dashboard for reviewing account balances, monthly cash flow, spending budgets, and recent transactions. It includes navigation between overview, transaction, and budget views, plus an interactive transaction form that updates the dashboard in the browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Netlify

## Deployment Process Summary

1. Organized the application as static HTML, CSS, and JavaScript files.
2. Initialized a Git repository and committed the complete project.
3. Published the repository to a public GitHub repository.
4. Created a Netlify site and connected it to the GitHub repository.
5. Deployed the project from the repository's default branch.
6. Changed the Netlify site name to a memorable SpendWise-related subdomain.
7. Made a content update and pushed it to GitHub to confirm continuous deployment.

## Challenges Encountered During Deployment

- Ensuring the page paths and asset paths work at the Netlify domain root.
- Choosing a Netlify subdomain that was still available.
- Verifying that third-party fonts and local CSS and JavaScript assets load on the live site.

## Lessons Learned

Using GitHub with Netlify turns every push to the connected branch into a deployment opportunity. Keeping static assets well-organized, checking live resources, and testing responsive views are essential for a reliable published website.
